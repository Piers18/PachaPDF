# Logo transparente

Se conserva el original aprobado en `public/brand/pachapdf-logo-aprobado.png`. La cabecera y los favicons consumen una variante transparente, creada con la herramienta integrada de edición de imágenes a partir del original. No sustituye el archivo maestro aprobado.

Archivo: `public/brand/pachapdf-logo-transparente.png`. Favicons derivados mediante Sharp: `public/brand/favicon-transparent-{16,32,48,180,192,512}.png`. Se quitó además el fondo blanco del contenedor CSS del logo.

Instrucción de edición: «Quitar sólo el fondo blanco exterior con transparencia real; conservar la llama morada, contorno y flecha turquesa, proporciones y el blanco interior del documento; sin rediseñar ni añadir elementos, con margen transparente para favicon». La edición mediante IA no garantiza identidad de píxeles con el original.

Comprobación del PNG: 1254 × 1254, canal alfa, esquina exterior RGBA (0,0,0,0); muestra interior del documento RGBA (253,252,252,254), visualmente blanca y prácticamente opaca. Se inspeccionó visualmente el resultado. Nombres nuevos para los iconos evitan reutilizar las URLs antiguas de caché.
